Student Management System

A command-line application built with Python to manage student records and grades.

Features

* Add new students
* Calculate student grade averages
* Display all student records
* Search for students by name
* Delete student records
* Validate grade inputs (0–100)
* Save student data using JSON

Technologies Used

* Python 3
* JSON
* Git
* GitHub
* Ubuntu Linux

How to Run

1. Clone the repository:

git clone YOUR_REPOSITORY_URL

2. Open the project folder:

cd student-management

3. Run the application:

python3 main.py

Purpose

This project was created to practice Python programming, file handling, data management, and Git version control.
